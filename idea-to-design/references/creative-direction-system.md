# Creative Direction System

Use before heavy image generation. Goal: make visuals context-fit, fresh enough, and not template-like without forcing every project to chase trends.

## Lightweight Default Check

Run these five checks for every visual direction:

- `Context Fit`: choose the right era and trust level for the product.
- `Audience Fit`: match user taste, risk tolerance, and usage context.
- `One Memorable Move`: give each core page one clear visual idea.
- `Anti-AI-Slop Risk`: identify likely template or empty-demo failure.
- `Real Content First`: use real Chinese product copy and plausible content before polish.

Keep the summary short.

## Context Fit

Pick one:

- `classic trusted`: finance, legal, medical, education, government, high-trust service.
- `modern practical`: SaaS, workflow tools, dashboards, B2B products.
- `warm lifestyle`: community, consumer, commerce, content, local service.
- `bold editorial`: brand site, launch page, campaign, creator product.
- `experimental`: art, culture, frontier tech, youth trend projects.

Traditional is allowed. It must feel refined, trustworthy, and precise, not old or lazy.

## Freshness Budget

Each core page gets 1-2 fresh moves only.

Examples:
- unusual hero composition
- editorial typography
- distinctive material palette
- layered information rhythm
- product process as visual path
- spatial dashboard or command-center framing

Do not use novelty to damage readability, trust, or task completion.

## One Memorable Move

For each core page, write one sentence:

`This page is memorable because ...`

If no sentence is possible, the direction is probably generic.

## Real Content First

Before image generation, provide realistic visible content:

- real page title
- real CTA text
- real card titles
- plausible data labels
- real empty/error/success text when visible

Do not use labels such as "这里是详情", "这里展示数据", "按钮文案", or "用户信息区域".

## Prompt Variation Matrix

Use only for core pages, home pages, marketing pages, or high-fidelity exploration.

When generating 2-3 options, vary at least 2-3 of:

- composition
- material
- density
- color strategy
- typography rhythm
- component shape
- visual hook

Keep product structure and CTA logic stable.

## Creative Direction Summary

Use this compact shape:

```text
Creative Direction Summary
- context_fit:
- audience_fit:
- freshness_level:
- visual_dna:
- memorable_move:
- anti_slop_risks:
- rejected_styles:
- next_prompt_constraints:
```

Write human-facing summaries in Chinese.
